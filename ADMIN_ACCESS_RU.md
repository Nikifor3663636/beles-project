# Аккаунты и права — актуальные правила 21.10.2026

Эти правила заменяют прежний предел в два аккаунта и повторное подтверждение пароля владельца при открытии разделов.

В «Мій акаунт» общая шапка профиля остаётся видимой, ниже находятся вкладки «Профіль», «Пароль і 2FA», «Сеанси», а у владельца — «Адміністратори та права». Открыта одна панель; поля сохраняют введённое при переключении вкладок. Есть клавиатурное переключение стрелками/Home/End и мобильная полоса вкладок.

Владелец имеет полный доступ во время действующего сеанса, без прежнего пятиминутного запроса пароля при открытии разделов. Вход в систему, изменение собственного пароля и настройка 2FA сохраняют свои проверки. CSRF, срок сеанса и защита входа остаются действующими.

Количество дополнительных администраторов не ограничено числом аккаунтов. Создание, отключение, удаление и изменение прав доступны только владельцу. Создать второго владельца или изменить права существующего владельца через API нельзя.

При создании выберите права на просмотр и редактирование: товары, бренды, партнёры, PDF, тексты, обращения, аналитика, код/дизайн, хранилище/журнал. Экспорт каталога и обращений выдаётся отдельно. Право редактирования автоматически включает просмотр своего раздела. Настройка GA4 относится к редактированию аналитики; очистка файлов — к редактированию хранилища. Полный доступ к разделам не даёт управление пользователями.

Новый аккаунт без выбранных прав получает доступ только к своему профилю. У ранее существовавших обычных администраторов сохраняются прежние права каталога, обращений и просмотра аналитики. Текущие пароли, имена и идентификаторы сохраняются.

Права можно изменить в раскрывающейся карточке пользователя. Сервер проверяет их при каждом запросе, включая уже открытые сеансы. Интерфейс после обновления скрывает недоступные разделы; прямые запросы запрещённых действий получают 403. Отключение/удаление завершает сеансы пользователя. Действия управления заносятся в аудит без паролей.

Проверки: конкурентное создание более двух администраторов, доступ владельца после истечения прежнего срока повторной проверки, режим только чтения, немедленная смена/отзыв прав, защита владельца и запрет самоназначения прав через профиль.
