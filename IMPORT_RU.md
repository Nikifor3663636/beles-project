# Импорт товаров по ссылке

Актуальная внешняя аналитика — Google Analytics 4, инструкция в `GOOGLE_ANALYTICS_RU.md`. Раздел о Clarity ниже сохранён как история прежней настройки; Microsoft Clarity отключён.

В админке откройте **Товары → Импорт за посиланням**, вставьте URL страницы товара и нажмите «Завантажити дані».

Импорт открывает обычную форму нового товара. Проверьте название, язык описания, изображение, бренд и характеристики, затем сохраните. До сохранения каталог не меняется. Кнопка «+ Додати» по-прежнему открывает ручное добавление.

Для «Чудо Острів» предусмотрен импорт сохранённой страницы, поскольку Cloudflare блокирует запросы с Railway. Откройте товар в своём браузере и дождитесь его загрузки, затем Ctrl+S → «Веб-страница, только HTML» (или полностью). В диалоге импорта укажите исходный URL, раскройте «Чудо Острів / сайт блокує імпорт?» и выберите сохранённый .html размером до 3 МБ. Нажмите «Завантажити дані»: название, фото, бренд, артикул и характеристики загрузятся в форму. HTML не исполняется и не сохраняется на сервере. Данные относятся к моменту сохранения страницы; сама страница проверки Cloudflare не подходит.

Поддерживаются общедоступные HTML-страницы: Product JSON-LD, Open Graph, метаданные, отдельные поля microdata и таблицы характеристик. Сайты с авторизацией, защитой от загрузки, динамическими данными только в JavaScript или нестандартной разметкой могут дать неполные данные либо отказ. При нескольких товарах выбирается первый; вариант нужно проверить вручную. Автоматического перевода и обновления цены нет. Цена источника, если найдена, попадает в характеристики.

Фотография используется по внешней ссылке. Если источник перестанет её отдавать, загрузите собственный файл в поле изображения. Неизвестный бренд нужно сначала создать в разделе «Бренды» или выбрать существующий при сохранении.

Импорт доступен только администраторам с проверкой CSRF. Внутренние адреса запрещены, DNS проверяется и фиксируется для соединения, каждое перенаправление проверяется заново. Лимиты: 18 секунд, 3 МБ HTML, 4 перенаправления.

# Расширенная аналитика

В разделе **Аналітика → Microsoft Clarity** вставьте Project ID своего проекта. Создайте проект на https://clarity.microsoft.com/ для адреса сайта; ID находится в Settings → Setup, в конце `https://www.clarity.ms/tag/ID`. Пароли и API-секреты не нужны. ID сохраняется на постоянном диске Railway. Пустое поле отключает интеграцию для новых загрузок сайта.

Кнопка «Відкрити Clarity» ведёт в ваш проект: там доступны записи сессий, тепловые карты и отчёты. Требуется вход в ваш аккаунт Microsoft Clarity. Сохранение ID не подтверждает права доступа или поступление данных — это проверяется в самом сервисе.

Посетитель разрешает запись отдельным баннером; без согласия скрипт Clarity не загружается. Отзыв согласия — через кнопку настроек записей в футере. Формы маскируются, рекламное согласие не предоставляется, посещения авторизованных администраторов исключены. Do Not Track и отключение общей аналитики учитываются. Clarity предназначен для сайтов, ориентированных на взрослых; данный каталог предназначен для покупателей и партнёров.

События: `beles_product`, `beles_brand`, `beles_pdf`, `beles_contact`, `beles_feedback`. Теги с такими же именами содержат ключ товара/бренда/PDF или тип контакта, без содержимого обращений. Для воронок можно выбрать эти события в Clarity. Встроенные отчёты работают независимо, история старых посещений в Clarity не переносится.
