# Редактор сайта

Админка → «Дизайн і блоки сайту».

Редактор показывает список блоков, код и живой результат рядом. Автопредпросмотр обновляется после небольшой паузы во вводе. Нажатие на блок в предпросмотре открывает его код; выбранный блок подсвечивается. Можно выбрать ширину телефона, планшета или компьютера. Для приостановки автоматических запросов снимите «Автоперегляд» и обновляйте результат вручную.

Код снабжён номерами строк; Tab вставляет два пробела, Ctrl+S / Cmd+S вызывает публикацию с подтверждением. Изменения выбранного блока остаются черновиком до нажатия «Опублікувати блок». При переходе к другому блоку с несохранёнными изменениями редактор спрашивает, нужно ли их отбросить.

Выберите раздел: цвета, дополнительные CSS, весь HTML/JavaScript, отдельный слой CSS или HTML-блок (шапка, главный экран, каталог, контакты, подвал и другие).

В каждом разделе есть ссылки «Скачати оригінал» и «Скачати поточний». Оригинал — состояние шаблона на момент установки редактора. Он хранится отдельно и не перезаписывается публикациями или развёртыванием. Новые блоки, созданные вручную, могут отсутствовать в оригинале: для них доступен текущий исходник.

«Відновити цей розділ» загружает оригинал в поле редактирования. Для применения нужно нажать «Опублікувати розділ». «Попередній перегляд» показывает неопубликованный результат в изолированном окне; формы, отправка аналитики и внешние скрипты в нём ограничены.

«Скасувати останню публікацію» возвращает предыдущую полную версию дизайна. Хранится один предыдущий вариант. «Відновити весь оригінал» восстанавливает начальный HTML, убирает дополнительные CSS и настройки цветов. Каталог, аккаунты, обращения и настройки Google Analytics эти операции не затрагивают.

Изменения HTML требуют аккуратности: служебные id и скрипты обеспечивают работу каталога, переключения языка и форм. Динамические тексты и контакты из существующего раздела «Тексти та контакти» имеют приоритет над текстами HTML. Редактирование HTML блока не является визуальным конструктором; весь код доступен в разделе полного HTML. Страница админки хранится отдельно и остаётся доступна для восстановления при ошибках дизайна.

Цветовые настройки меняют основной фон, основной текст, фон главного блока и основные кнопки. Индивидуальные цвета брендов и стили с собственными правилами настраиваются в соответствующих CSS или каталоге.

Постоянные файлы: `data/site-original.html`, `data/site-design.json`, `data/site-design.previous.json` внутри BELES_STORAGE_DIR. Предпросмотр хранится только в памяти сервера до 10 минут и доступен только создавшему его администратору. При одновременном редактировании двумя администраторами устаревшая версия не перезаписывает новые изменения.
