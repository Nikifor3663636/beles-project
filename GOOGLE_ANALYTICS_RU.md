# Google Analytics 4

Microsoft Clarity заменён интеграцией Google Analytics 4. Встроенные отчёты Beles продолжают работать отдельно.

## Подключение

1. Откройте https://analytics.google.com/ под своим аккаунтом.
2. Создайте ресурс GA4 и веб-поток для адреса сайта, если их ещё нет.
3. В разделе «Администратор → Потоки данных → Веб» скопируйте Measurement ID вида `G-XXXXXXXXXX`.
4. В админке Beles откройте «Аналітика → Google Analytics 4», вставьте ID и сохраните.
5. В гостевой вкладке сайта примите отдельное согласие Google Analytics. После этого проверяйте «Отчёты → В реальном времени» в нужном ресурсе GA4.

Пустое поле Measurement ID отключает Google Analytics. Старое согласие Microsoft Clarity не переносится на Google. Авторизованные администраторы, Do Not Track и сохранённое отключение аналитики исключаются. До согласия скрипт Google не загружается.

## События

- `page_view` — посещение страницы, стандартное событие Google tag.
- `view_item` — открытие товара; передаются ключ, название и бренд товара.
- `view_brand` — открытие бренда.
- `catalog_pdf_download` — нажатие на PDF каталога.
- `contact_click` — нажатие на телефон, email, Telegram или Instagram; передаётся только тип контакта.
- `generate_lead` — успешная отправка формы; содержимое обращения не передаётся.

Собственные обработчики не отправляют имя, контакт или текст сообщения. В адресе страницы удаляются query-параметры и hash; из referrer остаётся origin. Рекламное согласие и Google Signals отключены. Возможности расширенного измерения, сроки хранения и отчёты управляются в ресурсе GA4 владельца.

GA4 предназначен для отчётов по посещаемости и событиям. Записи экрана и тепловые карты Microsoft Clarity в него не переносятся. Старые данные остаются в прежнем аккаунте Clarity.

## Файлы

- `public/google-analytics.js` — Google tag, согласие и события.
- `/api/integrations` — защищённая настройка Measurement ID.
- `/api/public-integrations` — публичный ID для гостевой страницы; для авторизованного администратора ID пустой.
- `public/clarity.js` — инертный совместимый файл для старых сохранённых шаблонов; Microsoft не вызывается.
