BELES — сайт и админка

В Windows можно запустить START_BELES.cmd двойным щелчком.
Дождитесь строки «Beles:» и откройте http://localhost:3000.
Окно запуска должно оставаться открытым, пока вы пользуетесь сайтом.
Не открывайте data/base.html напрямую: это шаблон, который сервер
наполняет каталогом и связывает с изображениями и API.

1. Установите Node.js 22+ (рекомендуется 22).
2. Откройте терминал в папке проекта.
3. Выполните npm ci, затем npm start.
4. Откройте http://localhost:3000/admin
5. Введите одноразовый код из терминала и создайте первого администратора.

После этого публичная регистрация закрыта. Главный администратор в «Мій акаунт» может добавить второго администратора; максимум — два.
Сайт: http://localhost:3000
Подробная инструкция для хостинга: README_RU.md
Фото, PDF и шрифты уже находятся в uploads.
Для переноса существующей установки сохраните ваши data/admin.json, data/admin.initialized и data/feedback.json. Не заменяйте рабочий каталог без резервной копии.

Новые роли, 2FA, PostgreSQL, хранилища и восстановление: OPERATIONS_TZ_RU.md.
