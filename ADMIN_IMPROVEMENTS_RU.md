# Обновление 22.10.2026: партнёры и галерея товаров

Блок партнёров расположен после брендов, перед «Про нас» и контактами.
Порядок применяется также к ранее сохранённому пользовательскому шаблону.

Админка → «Товари» → «Редагувати» → «Фото та файли» → «Галерея у «Докладніше»».
Главное фото остаётся первым. Можно добавить до 20 дополнительных фото сразу
с компьютера (до 20 МБ каждое) или по ссылке, изменить порядок кнопками
«Раніше» / «Пізніше» и убрать фото из галереи. Затем нажмите «Зберегти зміни».
Удаление из галереи не удаляет исходный файл из хранилища.

В «Докладніше» доступны миниатюры, стрелки, клавиши ←/→ и свайп.
Нажатие на большое фото открывает увеличенный просмотр с переключением.
Для товаров с одним фото лишние элементы переключения скрыты.
Новая версия требует публикации кода на сервере; это описание не подтверждает деплой.

## Обращения

Контактная форма сохраняет сообщения в «Звернення». Добавлены поиск по имени,
контакту, тексту и артикулу, фильтры статуса, темы, дат UTC, сортировка по дате,

## Защита входа на сайте

«Мій акаунт → Пароль і 2FA → Додати Windows Hello / Face ID / ключ».
Нужны HTTPS, постоянный PUBLIC_URL и браузер с WebAuthn. Вход: пароль, затем ключ
устройства. TOTP можно оставить альтернативным вторым фактором. Google Authenticator
для ключей не нужен. Включить настоящий ключ может только сам владелец устройства.

Добавление требует текущего пароля и уже включённого второго фактора. Резервные
коды показываются один раз; добавление ключа заменяет предыдущие резервные коды
ключей. Сохраните их отдельно. Для следующего/удаления ключа используйте пароль
и резервный код либо TOTP. Изменение защиты завершает другие сеансы. Автоматического
обхода при потере ключа и кодов нет. На другом домене нужен резервный код.

Биометрия остаётся на устройстве. Сервер хранит публичный ключ, счётчик и хеши
резервных кодов; проверяет домен, origin, подпись, подтверждение пользователя
и одноразовый challenge (3 минуты). Приватный ключ сайт не получает.

## Аналитика

График: линии/столбцы, три переключаемых ряда, ось значений, подсказки, таблица.
IP, устройство, браузер, последний визит, просмотры, онлайн доступны с правом
`analytics.read`. IP хранятся 7 календарных дней UTC, затем очищаются; агрегаты —
до 90 дней. Старые IP не восстановить. IP VPN/NAT не идентифицирует человека.
Вне доверенного прокси показывается адрес соединения. Railway X-Real-IP принимается
только в Railway через внутреннюю сеть. IP из JSON и недоверенных заголовков
игнорируются. Do Not Track и отказ от аналитики учитываются; текущие админские
посещения не учитываются.

## Визуальный редактор

«Дизайн і блоки сайту»: нажмите элемент в предпросмотре и меняйте текст, ссылку,
изображение, цвета, шрифт, отступ, скругление, видимость через поля. Код доступен
отдельным режимом. Alt+клик управляет предпросмотром (например, открывает бренд),
обычный клик выбирает элемент. Поддерживаются исходные и созданные скриптами элементы.

Свойства динамических элементов применяются после появления элемента. После
изменения порядка/структуры каталога может потребоваться повторно выбрать элемент.
Названия, цены и описания конкретных товаров надёжнее менять в каталоге. Для
собственного текста есть украинское и английское поля; другие языки используют
английский или основной текст. Новый текст сам не переводится.

Предпросмотр изолирован от аккаунта и сетевой отправки форм. Есть скачивание
доступных исходников, предыдущая версия и история 10 публикаций. Развёртывание
не заменяет опубликованный пользовательский шаблон базовым.

Проверки: `npm test`, реальные тестовые подписи WebAuthn и проверки origin,
счётчика, повторов, резервных кодов; безопасные поля, восстановление, сроки IP.
Также выполнена локальная проверка интерфейса в браузере.
